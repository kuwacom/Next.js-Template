# Guides

`content/docs/guides/index.mdx` を置くと、このファイルは `/docs/guides` に公開されます。

- フォルダ配下のトップページとして使えます
- 子ページへの導線や概要説明をまとめられます
- `content/docs/guides/writing-docs.mdx` のような通常記事と共存できます

## 例

- [Writing Docs](/docs/guides/writing-docs)

> フォルダごとにトップページを持たせたい場合は、各ディレクトリに `index.mdx` を追加してください。
