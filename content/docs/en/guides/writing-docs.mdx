# How to Add Articles

Subdirectories are supported under `content/docs/`. If you want to organize content by category, a normal folder structure is enough.

## Recommended organization

- Put guide articles in `content/docs/guides/`
- Put reference articles in `content/docs/reference/`
- Slugs are generated automatically from file names

## Example format

Standard Markdown syntax works as-is.

```ts
export async function generateStaticParams() {
  return [{ slug: ["guides", "writing-docs"] }]
}
```

> Code blocks, blockquotes, and lists are formatted automatically.

<Callout variant="warn" title="Note">
  If you add `draft: true` to `metadata`, the article is excluded from indexes and public routes.
</Callout>
