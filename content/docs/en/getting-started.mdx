# Getting Started with the MDX Docs System

In this template, `.mdx` files placed under `content/docs/` are published to `/docs/*`.

<Callout variant="tip" title="Fastest workflow">
  Add `content/docs/your-article.mdx` and export `metadata` at the top. It will appear in both the index and the detail page automatically.
</Callout>

## How routing works

- `content/docs/getting-started.mdx` -> `/docs/getting-started`
- `content/docs/guides/writing-docs.mdx` -> `/docs/guides/writing-docs`

## Writing metadata

At the top of each article, export metadata like this:

```tsx
export const metadata = {
  title: "Article title",
  description: "Description used in listings and meta tags",
  publishedAt: "2026-03-14",
  tags: ["MDX", "Docs"],
}
```
