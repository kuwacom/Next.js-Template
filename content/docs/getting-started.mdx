# MDX 記事システムの始め方

このテンプレートでは、`content/docs/` ディレクトリに置いた `.mdx` ファイルが Velite でビルドされ、`/docs/*` に公開されます。

<Callout variant="tip" title="最短フロー">
  `content/docs/your-article.mdx` を追加し、先頭に frontmatter を書けば一覧にも詳細ページにも反映されます。
</Callout>

## ルーティングの考え方

- `content/docs/getting-started.mdx` → `/docs/getting-started`
- `content/docs/guides/writing-docs.mdx` → `/docs/guides/writing-docs`

## frontmatter を書く

各記事の先頭では、次の形式でメタデータを書きます。

```tsx
---
title: 記事タイトル
description: 一覧やメタタグに使う説明文
publishedAt: 2026-03-14
tags:
  - MDX
  - Docs
draft: false
---
```

## MDX コンポーネント

標準の Markdown に加えて、いくつかの React コンポーネントもそのまま使えます。

<Badge variant="secondary">Badge</Badge>

<Callout variant="info" title="使えるもの">
  現在は `Badge` と `Callout` をグローバル登録しています。必要になったら `mdx-components.tsx` に追加できます。
</Callout>

## 次にやること

1. `content/docs/` に新しい `.mdx` を追加する
2. frontmatter を書く
3. ブラウザで `/docs` を開く
